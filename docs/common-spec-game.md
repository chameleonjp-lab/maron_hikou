### 変更と理由

- 未送信結果は正確な保存と読み戻しができるまで送信しない。保存拒否・容量不足でも結果と複数の未送信をメモリに残し、回復後同じUUID/payloadで再送する。再読み込みせず保存可能な状態へ戻す警告を15言語に追加（計97文）。
- 同UUID別payload・破損した原文は上書きしない。該当するものだけ送信を保留し、他の未送信は続行。受付成功の記録はtombstoneとして保存し、再確定・再読み込みで二重送信を作らない。上記「成功後除去」という旧説明は今回の保持方式に置き換わる。
- ACKは既存normal receipt RPCの1行TABLE・9列型を検証。名前正規化は現在のbtrimのみ契約を保持。signedなサーバー旧値を勝手に破棄しない。UUID/現在スコアを返さないRPCなので、それらの完全なサーバーreadbackまで検証したとはしない。
- queue確定競合例外で結果画面が開かない問題を修正。結果は独立して保存・表示し失敗状態を示す。古いrunの通知は現在のplay IDが一致した場合だけ反映する。
- AudioContextのinterrupted/suspendedで既存の声を停止し、復帰後に古い音を鳴らさない。oscillator切断の失敗でもgainを別に切断する。既存のoff/音量0・同期resume旧イベントdropは維持。

30波・強化乱数・進行度×10,000,000+表示スコア（上限9,999,999）、リタイア/audit_seedの公開・自己ベスト除外、名前/自己ベストキーは維持する。共通キュー採用を理由にゲーム固有の採点や監査条件を変えない。
