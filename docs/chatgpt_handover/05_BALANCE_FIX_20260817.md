# バランス調整実装ログ（2026-08-17）

## 目的

W5の強化抽選への依存、W21以降の難易度要素の重なり、逃走・戦利品消失が結果画面から分からない問題を先に改善する。

## 今回の対応

- 初回レベルアップの候補を「弾数+1」「連射速度アップ」に限定。
- W21では敵数とHPだけを増やし、敵弾の発射間隔短縮をW26から開始。
- W26〜29の通常敵数を小さく減らし、Tier3ボスの攻略を主役にする。
- プレイヤー追従補間を経過時間基準に変更し、フレームレートによる操作差を抑える。
- 結果画面に「逃走」「未回収」を追加。
- 画面外へ落ちた戦利品と、同時表示上限で消えた戦利品を未回収数として記録。

## 今回は変更していないもの

- ボスの各弾幕発射前の予告演出。
- 固定シードによる実測バランス監査。
- クライアントから送信するランキング値のサーバー検証。
- 逃走数をスコアへ直接反映するルール。

これらは今回の変更後にプレイデータを確認してから判断する。

## 確認

- `index.html` のscript部分を構文解析し、エラーがないことを確認。
- 変更差分を読み直し、初期化・リセット・結果表示の対応を確認。
- 実機でのW5、W21、W25〜30のプレイ確認は、Draft PR確認後に行う。
