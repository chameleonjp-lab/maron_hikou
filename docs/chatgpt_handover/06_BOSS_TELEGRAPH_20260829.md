# ボス攻撃予告の実装記録（2026-08-29）

## 目的

ボス戦で、被弾するまで攻撃方向が分からない状態を減らす。
予告を装飾にせず、表示された軌道と実際に発射される弾道を一致させる。

## 実装内容

- ボスの通常弾幕を発射前0.55秒から予告。
- 3方向・5方向弾は、実際の弾と同じ角度の赤い破線を表示。
- 狙い撃ちと狙い撃ち2連は、予告開始時のプレイヤー位置を固定し、線と照準で着弾方向を表示。
- Tier 3の12方向円形弾は、12本の放射線と広がる円で予告。
- 通常弾幕と円形弾の予告が重なる場合も、それぞれを同時に表示。
- ルール説明へ、赤い線と円の意味を追加。
- 古いW21の弾密度コメントを、実装値に合わせて修正。

## 公平性上の判断

狙い撃ちの予告中にプレイヤーが移動すると、予告線と発射方向がずれる問題が起きる。
そのため、狙い位置は予告を始めた時点で固定した。
これにより、予告を確認して移動する時間と、表示された攻撃方向が一致する。
